# Cat Photo App

My first real HTML project from freeCodeCamp's Responsive Web Design course. It's a small page about cats, with photos, a couple of lists, and some links.

Nothing fancy yet, no CSS. I just wanted to get the structure right first.

## What's on the page

- A heading and a few sections
- Links, one of them opens in a new tab
- Images with alt text
- A list of things cats love and a list of things cats hate
- Figures with captions
- A footer

## What I practiced

- Semantic tags like `main`, `section`, `figure`, `figcaption` and `footer`
- Ordered and unordered lists
- Using `em` and `strong` properly
- Writing alt text so the images still make sense without seeing them

## Running it

No setup needed. Download `cat.html` and open it in any browser.
